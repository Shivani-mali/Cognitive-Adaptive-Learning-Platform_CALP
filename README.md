# Cognitive Adaptive Learning Platform (CALP) - LearnAble AI

> **"Adapting Learning to the Way You Think"**

Welcome to the **Cognitive Adaptive Learning Platform (CALP)**, also known as **LearnAble AI**!

CALP is an original, custom-engineered educational ecosystem designed to revolutionize how individuals consume knowledge. By combining advanced AI intelligence, adaptive learning pathways, cognitive focus modes, and dynamic multimedia, CALP transforms traditional passive learning into an active, personalized cognitive journey.

---

## 🎯 Project Motto & Vision

### **Motto**: *"Adapting Learning to the Way You Think"*

Our core vision is based on a fundamental truth: **No two minds process information in the exact same way.** Standard educational tools force every student into a rigid, one-size-fits-all model. CALP breaks this barrier by dynamically adapting content depth, visual support, step-by-step guidance, and interactive self-assessments to align directly with each learner's unique cognitive state and focus needs.

---

## 🌟 Significance & Originality (Not a Template or Copy-Paste Project)

CALP is **not** a generic template or copy-pasted wrapper application. It is a ground-up, custom-architected full-stack platform built with intentional design decisions, state-of-the-art UI ergonomics, and specialized cognitive learning modes:

### 1. 🧠 Custom Cognitive Learning Engines
Unlike simple chat wrappers, CALP features specialized adaptive teaching modes:
- **Step-by-Step Mode**: Deconstructs complex topics into clear, progressive learning milestones.
- **Easy Read Mode**: Uses simplified vocabulary and high-readability formatting to support neurodiverse learners and quick comprehension.
- **Focus Mode**: Delivers concise, distraction-free explanations designed for fast retention and minimal cognitive overload.
- **Structured Mode**: Generates comprehensive syllabus maps, bulleted takeaways, educational illustrations, and embedded multimedia.

### 2. 🎨 Premium Glassmorphism & Focused UI/UX
Designed with modern aesthetic principles—fluid glassmorphism, dynamic background ambience, cinematic light particles, soft gradients, and zero clutter—ensuring learners remain immersed and focused.

### 3. 📊 Real-Time Progress Tracking & Memory Persistence
Features live user statistics, streak counters, historical chat persistence, role-based pathways (Student & Parent/Guardian Dashboards), and real-time Firestore synchronization.

### 4. 🖼️ Dynamic Multimedia Augmentation
Automatically enriches text explanations with curated educational imagery and targeted video demonstrations dynamically retrieved for complex topics.

---

## 🚀 Key Features

- **Adaptive AI Tutor**: Generates custom syllabi ("Learning Paths") and tailored responses based on user queries and selected cognitive modes.
- **Interactive Knowledge Checks**: Embedded quizzes and instant feedback options (*Clear*, *Got it!*, *Confused*) to reinforce active recall.
- **Student & Parent Portals**: Dual-role experience allowing students to explore topics freely while parents track learning progress and engagement metrics.
- **Seamless Authentication**: Flexible user access featuring Firebase Authentication (Email/Password & Google Sign-In) and a dedicated Guest Mode.

## 🛠️ Technology Stack

- **Frontend**: React.js, Vite, Vanilla CSS Modules, React Router
- **Backend**: Node.js, Express.js, REST APIs
- **Database & Auth**: Firebase Authentication, Cloud Firestore
- **AI & Data Integration**: Google Gemini AI (`@google/generative-ai`), OpenAI API, Unsplash API, YouTube Data API
- **Deployment**: Vercel

## 💻 Local Setup & Run

### Prerequisites
- Node.js (v16 or higher)
- Git

### 1. Clone the repository
```bash
git clone https://github.com/Shivani-mali/Cognitive-Adaptive-Learning-Platform_CALP.git
cd Cognitive-Adaptive-Learning-Platform_CALP
```

### 2. Backend Setup
```bash
cd backend
npm install
npm start
```
*The backend server will start on http://localhost:5000*

### 3. Frontend Setup
Open a new terminal window:
```bash
cd frontend
npm install
npm run dev
```
*The frontend development server will run on http://localhost:5173*
